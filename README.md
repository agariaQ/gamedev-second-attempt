# gamedev-second-attempt

small 3D racing game made with Unity 6 (6000.3.24f1, URP)

## Start

1. Install [Git LFS](https://git-lfs.com) before cloning (models, textures and sounds are stored with LFS).
2. Open the project in Unity 6000.3.24f1.
3. Open `Assets/Scenes/Main.unity` and press **Play**.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Accelerate | W / ↑ | Right trigger |
| Brake / reverse | S / ↓ | Left trigger |
| Steer | A D / ← → | Left stick |
| Handbrake | Space | X / □ |
| Reset to last checkpoint | R | View / Share |
| Pause | Esc | Start / Options |
